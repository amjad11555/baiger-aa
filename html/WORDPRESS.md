# إضافة موقع BAIGR إلى صفحة ووردبريس

## لماذا لم يعمل اللصق المباشر؟

`baigr-preview.html` صفحة HTML **كاملة** (فيها `<html>` و`<head>` وكل المكتبات
مدمجة). لصقها داخل صفحة ووردبريس يسبب:

- **ثِقَل شديد** — الملف المدمج ~2.4 ميغابايت.
- **لا تفتح صح** — ووردبريس يحذف/يكرّر وسوم `<html>`/`<head>`.
- **تكسّر التجاوب** — أسماء الفئات (`.container`, `.section`, `.btn`) تتصادم مع
  تنسيقات القالب، والتمرير الناعم (Lenis) يختطف تمرير صفحة ووردبريس كلها.

الحل الصحيح: عزل التصميم داخل **iframe**. هذا يمنع أي تصادم مع القالب، ويجعل
التمرير والحركات والتجاوب تعمل تماماً كما في صفحة المعاينة.

استخدم `baigr-embed.html` (~134 كيلوبايت فقط — المكتبات والخط تُحمّل من CDN).

---

## الطريقة (خطوة بخطوة)

### 1) ارفع الملف إلى استضافتك

`baigr-embed.html` **ملف واحد**. ارفعه إلى استضافتك عبر cPanel → File Manager
أو FTP، مثلاً إلى المجلد الجذر `public_html/`. سيصبح رابطه:

```
https://your-domain.com/baigr-embed.html
```

> ملاحظة: مكتبة وسائط ووردبريس تمنع رفع ملفات `.html` افتراضياً، لذا استخدم
> File Manager أو FTP. (بديل بلا رفع في الأسفل.)

### 2) اجعل الصفحة بعرض كامل

أنشئ صفحة جديدة، ومن إعدادات القالب (Template) اختر **Full Width** أو
**Blank / Canvas** (في Elementor: قالب "Canvas"). هذا يمنع الشريط الجانبي
والحاوية الضيّقة من عصر التصميم.

### 3) الصق كتلة الدمج

أضف كتلة **Custom HTML** (أو ويدجت HTML في Elementor) والصق:

```html
<iframe
  src="https://your-domain.com/baigr-embed.html"
  title="BAIGR"
  loading="lazy"
  allow="gyroscope; accelerometer"
  style="width:100%; height:100vh; border:0; display:block;"
></iframe>
```

انتهى. التصميم سيملأ الشاشة، يتمرّر بسلاسة داخل الإطار، ومتجاوب على كل المقاسات،
دون أي تعارض مع قالبك.

---

## بديل بلا رفع ملفات (srcdoc)

إن لم تستطع رفع ملف إلى الاستضافة، افتح `baigr-embed.html` بمحرر نصوص، انسخ
محتواه كاملاً، وضعه داخل خاصية `srcdoc` لإطار (استبدل علامات `"` بـ `'` داخل
المحتوى، أو أحِط الـ srcdoc بعلامات `'`). أبسط منه: استخدم إضافة مثل
**"HTML File Upload"** أو **"WP File Manager"** لرفع الملف ثم استخدم طريقة الـ iframe
أعلاه — أنظف وأخف.

---

## ضبط الارتفاع

- `height:100vh` = بارتفاع الشاشة، والمحتوى يتمرّر داخل الإطار (الخيار المستقر).
- لو أردت ارتفاعاً ثابتاً: بدّل `100vh` بقيمة مثل `900px`.

## تغيير رقم واتساب

قبل الرفع، افتح `baigr-embed.html` وابحث عن `wa.me/905000000000` واستبدله برقمك
(بصيغة دولية بلا + أو أصفار بادئة)، ثم ارفع الملف المحدَّث.

## بديل بلا اعتماد على CDN

لو أردت ألا يعتمد الموقع على أي CDN، ارفع مجلد `html/` كاملاً بدل الملف الواحد،
ثم أشِر بالـ iframe إلى `.../baigr/index.html`. أثقل قليلاً في أول تحميل لكنه
يعمل بلا إنترنت خارجي.
