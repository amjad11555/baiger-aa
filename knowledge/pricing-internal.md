## 3. نظام WhatsApp للشركات

**نموذج مختلف عن باقي الخدمات: منتج قالبي باشتراك، لا مشروع بسعر واحد.**

```
رسوم إعداد (تعادل شهرين إلى ثلاثة اشتراكات) + اشتراك شهري ثابت لكل فرع
```

| البند | القيمة |
| --- | --- |
| الاشتراك الشهري للفرع الأول |  |
| الفرع الثاني وما بعده | **نصف سعر الفرع الأول** |
| رسوم الإعداد | **ما يعادل شهرين إلى ثلاثة اشتراكات** |
| سقف الرسائل الشهري |  |
| سعر تجاوز السقف |  |

**قواعد التسعير:**
- ⛔ **لا يُسعَّر بالرسالة إطلاقاً** — يجعل العميل يخاف من النجاح ويحاسبنا على كل زيادة.
- سقف الرسائل الشهري **يُذكر للعميل من البداية**، لا يُكتشف لاحقاً.
- تكلفة قوالب واتساب **محمّلة داخل السعر**، لا تُفصل في فاتورة منفصلة.
- التسعير بسيط وثابت — لا جداول معقدة ولا شرائح.

**ما يبرر استمرار الاشتراك (نقاط الالتصاق):**
- **التقويم** — مواعيده تُحجز داخل النظام، فالإلغاء يعني خسارة تقويمه.
- **التذكيرات** — إيقافها يعيد نسبة الغياب فوراً في نفس الأسبوع؛ أوضح ألم عند التفكير بالإلغاء.
- **التقرير الشهري** — ورقة واحدة كل شهر تبرر الفاتورة بصمت.
- **رقم الواتساب والقوالب المعتمدة تحت حسابنا** — نقلها متعب عليه.
