# baigr — نظام رد آلي بيعي عبر واتساب 🤖💼

نظام رد آلي مخصص لوكالة **baigr** يعمل عبر **WhatsApp Cloud API** (الرسمي من Meta)
ومدعوم بنموذج **Claude**. يتصرّف كمستشار مبيعات بشري بارع: يفهم العميل، يجيب بلغة
سهلة وطبيعية، يعالج الاعتراضات باحتراف، ويقود المحادثة نحو إغلاق الصفقة — دون أن يبدو آليًا.

## المميزات
- **لا يبدو آليًا**: عربية طبيعية قريبة من لهجة العميل، رسائل قصيرة، مؤشّر "يكتب الآن...".
- **رد بعد ~10 ثوانٍ**: ينتظر ليجمع الرسائل المتتابعة في رد واحد ذكي (يشبه سلوك الإنسان)، وقابل للتعديل.
- **خبير بيعي**: منهجية SPIN، تأطير القيمة، معالجة الاعتراضات (السعر/الثقة/التوقيت)، الإغلاق.
- **حفظ دائم (SQLite)**: المحادثات وملفات العملاء تبقى بعد إعادة التشغيل.
- **نظام CRM مدمج**: تتبّع مرحلة كل عميل بيعيًا (جديد → مهتم → ساخن → مغلق) تلقائيًا.
- **تنبيهات الصفقات الساخنة**: يُنبّه صاحب الوكالة فورًا عند جاهزية عميل للشراء.
- **متابعة تلقائية للعميل الصامت**: أقوى رافعة مبيعات — يعيد إشعال الاهتمام بذكاء دون إلحاح.
- **تحويل لمختص بشري**: في الحالات الحرجة يتوقف الرد الآلي ويُخطر الفريق.
- **فهم الصور**: يحلّل الصور التي يرسلها العميل (لقطات، متطلبات) عبر رؤية Claude.
- **تفريغ الرسائل الصوتية**: يفرّغ الرسائل الصوتية عربيًا ويردّ عليها (عبر خدمة Whisper).
- **أمان واحترافية**: التحقق من توقيع Meta، منع تكرار الردود، إلغاء اشتراك، لوحة إحصائيات.
- **معرفة عمل قابلة للتعديل** عبر ملف واحد (`config/knowledge.md`).
- **صادق**: لا يختلق أسعارًا أو وعودًا خارج ملف المعرفة.

## البنية
```
src/
  index.js     ← خادم Express + Webhook + الأمان + منطق الرد + لوحة الإدارة
  whatsapp.js  ← إرسال الرسائل + مؤشّر الكتابة + تنزيل الصور
  brain.js     ← توليد الرد عبر Claude + حلقة أدوات المبيعات + الرؤية
  tools.js     ← أدوات المبيعات (تتبّع العميل CRM + التحويل البشري)
  followup.js  ← محرّك المتابعة التلقائية للعملاء الصامتين
  prompt.js    ← شخصية مندوب المبيعات (system prompt)
  store.js     ← الحالة اللحظية + غلاف قاعدة البيانات
  db.js        ← الحفظ الدائم (SQLite): محادثات، عملاء، تنبيهات، منع تكرار
  notify.js    ← تنبيهات صاحب الوكالة
  config.js    ← الإعدادات من متغيرات البيئة
config/
  knowledge.md ← معرفة العمل (خدماتك، أسعارك، عروضك) — عدّلها!
data/
  baigr.db     ← قاعدة البيانات (تُنشأ تلقائيًا)
```

## القدرات الاحترافية (كيف تعمل)
- **الحفظ الدائم**: كل رسالة وملف عميل يُحفظ في SQLite؛ يستأنف البوت من حيث توقّف بعد إعادة التشغيل.
- **CRM تلقائي**: يستدعي البوت أداة `update_lead` أثناء الحديث ليحدّث مرحلة العميل واهتمامه وميزانيته.
- **تنبيه الصفقات الساخنة**: عند وصول العميل لمرحلة `hot`/`negotiating` يصل تنبيه فوري لـ `OWNER_WA_ID`.
- **المتابعة التلقائية**: يفحص النظام دوريًا العملاء الذين صمتوا (ضمن نافذة 24 ساعة) ويرسل رسالة متابعة ذكية — حتى `FOLLOWUP_MAX` مرات.
- **حجز المكالمات**: أداة `book_call` تأخذ وقت العميل المناسب، ترفعه لـ "ساخن"، وتُخطرك للاتصال.
- **تذكير المكالمة**: يذكّر العميل قبل موعده (نص عادي ضمن 24 ساعة، أو قالب معتمد خارجها).
- **متابعة بعد يومين**: يتواصل تلقائيًا مع من لم يُغلق الصفقة عبر قالب معتمد (خارج 24 ساعة).
- **التحويل البشري**: أداة `escalate_to_human` توقف الرد الآلي وتُخطر الفريق؛ استأنفه عبر `/release`.
- **فهم الصور**: تُنزَّل صور العميل وتُحلَّل عبر رؤية Claude.
- **الأمان والموثوقية**: تحقق من توقيع `X-Hub-Signature-256`، ومنع تكرار ردود Meta، وإلغاء اشتراك بكلمات مثل «ايقاف».

## لوحة الإدارة (محمية بـ `ADMIN_KEY`)
- `GET /stats?key=...` — إحصائيات: عدد العملاء، الرسائل، توزيع المراحل، التنبيهات المفتوحة.
- `GET /release?wa=RECIPIENT&key=...` — استئناف الرد الآلي لعميل بعد التحويل البشري.

## خطوات التشغيل

### 1) التثبيت
```bash
npm install
cp .env.example .env
```
ثم عبّئ القيم في `.env` (انظر الأسفل).

### 2) عبّئ معرفة العمل
افتح `config/knowledge.md` واملأ خدماتك، باقاتك، أسعارك، عروضك، والأسئلة الشائعة.
كلما كان الملف أدق، كان الإقناع أقوى.

### 3) إعداد WhatsApp Cloud API (من Meta)
1. أنشئ تطبيقًا على [developers.facebook.com](https://developers.facebook.com/) من نوع **Business**.
2. أضِف منتج **WhatsApp**، واربط رقمًا (أو استخدم رقم الاختبار المؤقت).
3. من لوحة WhatsApp احصل على:
   - **Access Token** ← ضعه في `WHATSAPP_TOKEN` (يُفضّل توليد رمز دائم Permanent Token).
   - **Phone Number ID** ← ضعه في `WHATSAPP_PHONE_NUMBER_ID`.
4. اختر رمز تحقق سريًا وضعه في `WHATSAPP_VERIFY_TOKEN` (نفسه ستضعه في خطوة Webhook).

### 4) مفتاح Claude
ضع مفتاح Anthropic في `ANTHROPIC_API_KEY`. النموذج الافتراضي `claude-opus-5`
(الأذكى للإقناع). لتكلفة أقل مع جودة عالية جدًا استخدم `MODEL=claude-sonnet-5`.

### 5) شغّل الخادم واعرضه للإنترنت
```bash
npm start
```
الخادم يعمل على `PORT` (افتراضيًا 3000). لتجربته محليًا اعرضه عبر نفق مثل
[ngrok](https://ngrok.com/): `ngrok http 3000` — ستحصل على رابط `https://...`.
للإنتاج انشره على أي خادم يدعم HTTPS (Railway / Render / VPS...).

### 6) اربط الـ Webhook داخل Meta
في إعدادات WhatsApp > Configuration > Webhook:
- **Callback URL**: `https://نطاقك/webhook`
- **Verify token**: نفس `WHATSAPP_VERIFY_TOKEN`.
- بعد التحقق، اشترك في حقل **messages**.

الآن أي رسالة تصل رقمك ستُقرأ، ويظهر مؤشّر الكتابة، وبعد ~10 ثوانٍ يصل ردّ بيعي ذكي. ✅

## متغيرات البيئة
| المتغير | الوصف |
|---|---|
| `WHATSAPP_TOKEN` | رمز الوصول من Meta |
| `WHATSAPP_PHONE_NUMBER_ID` | معرّف رقم الهاتف |
| `WHATSAPP_VERIFY_TOKEN` | رمز التحقق (تختاره أنت) |
| `ANTHROPIC_API_KEY` | مفتاح Claude |
| `MODEL` | النموذج (افتراضي `claude-opus-5`) |
| `REPLY_DELAY_MS` | الانتظار قبل الرد بالمللي ثانية (افتراضي 10000) |
| `WHATSAPP_APP_SECRET` | سر التطبيق للتحقق من توقيع الويبهوك (يُنصح به) |
| `DB_PATH` | مسار قاعدة البيانات (افتراضي `data/baigr.db`) |
| `OWNER_WA_ID` | رقم صاحب الوكالة لتنبيهات الصفقات الساخنة والتحويل |
| `ADMIN_KEY` | مفتاح حماية لوحة `/stats` و `/release` |
| `FOLLOWUP_ENABLED` | تفعيل المتابعة التلقائية (افتراضي true) |
| `FOLLOWUP_HOURS` | بعد كم ساعة صمت نتابع (افتراضي 6) |
| `FOLLOWUP_MAX` | أقصى عدد رسائل متابعة لكل عميل (افتراضي 2) |
| `VOICE_API_KEY` | مفتاح خدمة تفريغ الصوت (Whisper) — يُفعّل التفريغ تلقائيًا |
| `VOICE_API_URL` | واجهة التفريغ (OpenAI افتراضيًا؛ Groq مدعوم) |
| `VOICE_MODEL` | نموذج التفريغ (`whisper-1` أو `whisper-large-v3`) |
| `HUMAN_HANDOFF_NOTE` | رسالة التحويل لمختص بشري |

## ملاحظات
- الحفظ الآن دائم عبر **SQLite** (`data/baigr.db`). خذ نسخة احتياطية من هذا الملف دوريًا.
  للتوسّع لعدة خوادم يمكن لاحقًا استبدال `db.js` بـ Postgres بنفس الواجهة.
- واتساب يسمح بالردود الحرة **ضمن نافذة 24 ساعة** من آخر رسالة للعميل. المتابعة التلقائية
  تحترم هذا الحد (تعمل خلال 23 ساعة فقط)؛ لمراسلة عملاء خارج النافذة تحتاج قوالب رسائل معتمدة من Meta.
- **الصوت** يُفرّغ عربيًا عند ضبط `VOICE_API_KEY` (خدمة متوافقة مع Whisper مثل OpenAI أو Groq)؛
  بدونه يعتذر البوت بلطف ويطلب الكتابة. **الصور** مدعومة عبر رؤية Claude. الملفات تُتجاهل بأمان.

## قوالب واتساب (مهم للتذكير والمتابعة بعد يومين)
واتساب يمنع الرسائل الحرة **بعد 24 ساعة** من آخر رسالة للعميل — تحتاج **قالبًا معتمدًا** من Meta:
1. من WhatsApp Manager > Message Templates أنشئ قالبين باللغة العربية واعتمدهما:
   - **قالب التذكير** (متغيّر واحد `{{1}}` = وقت المكالمة)، مثال نصّه:
     `تذكير بموعد مكالمتنا: {{1}}. نتطلع للتحدث معك! — baigr`
   - **قالب المتابعة** (متغيّر واحد `{{1}}` = اسم العميل)، مثال:
     `مرحبًا {{1}} 👋 لاحظنا اهتمامك بخدماتنا في baigr ونحب نكمل معك. تحب نحدّد وقت مكالمة قصيرة؟`
2. ضع اسمَي القالبين في `.env`: `REMINDER_TEMPLATE` و `REENGAGE_TEMPLATE`.
- بدون هذين القالبين: يعمل التذكير **فقط ضمن 24 ساعة** (رسالة نصية)، ومتابعة اليومين تتوقف مع تنبيه في السجل.
