# baigr — نظام رد آلي بيعي عبر واتساب 🤖💼

نظام رد آلي مخصص لوكالة **baigr** يعمل عبر **WhatsApp Cloud API** (الرسمي من Meta)
ومدعوم بنموذج **Claude**. يتصرّف كمستشار مبيعات بشري بارع: يفهم العميل، يجيب بلغة
سهلة وطبيعية، يعالج الاعتراضات باحتراف، ويقود المحادثة نحو إغلاق الصفقة — دون أن يبدو آليًا.

## المميزات
- **لا يبدو آليًا**: عربية طبيعية قريبة من لهجة العميل، رسائل قصيرة، مؤشّر "يكتب الآن...".
- **رد بعد ~10 ثوانٍ**: ينتظر ليجمع الرسائل المتتابعة في رد واحد ذكي (يشبه سلوك الإنسان)، وقابل للتعديل.
- **خبير بيعي**: منهجية SPIN، تأطير القيمة، معالجة الاعتراضات (السعر/الثقة/التوقيت)، الإغلاق.
- **ذاكرة محادثة** لكل عميل.
- **معرفة عمل قابلة للتعديل** عبر ملف واحد (`config/knowledge.md`).
- **صادق**: لا يختلق أسعارًا أو وعودًا خارج ملف المعرفة، ويحوّل الحالات الحرجة لمختص بشري.

## البنية
```
src/
  index.js     ← خادم Express + Webhook + منطق الانتظار والرد
  whatsapp.js  ← إرسال الرسائل + مؤشّر الكتابة (WhatsApp Cloud API)
  brain.js     ← توليد الرد عبر Claude
  prompt.js    ← شخصية مندوب المبيعات (system prompt)
  store.js     ← ذاكرة المحادثات + تجميع الرسائل
  config.js    ← الإعدادات من متغيرات البيئة
config/
  knowledge.md ← معرفة العمل (خدماتك، أسعارك، عروضك) — عدّلها!
```

## خطوات التشغيل

### 1) التثبيت
```bash
npm install
cp .env.example .env
```
ثم عبّئ القيم في `.env` (انظر الأسفل).

### 2) عبّئ معرفة العمل
افتح `config/knowledge.md` واملأ خدماتك، باقاتك، أسعارك، عروضك، والأسئلة الشائعة.
كلما كان الملف أدق، كان الإقناع أقوى.

### 3) إعداد WhatsApp Cloud API (من Meta)
1. أنشئ تطبيقًا على [developers.facebook.com](https://developers.facebook.com/) من نوع **Business**.
2. أضِف منتج **WhatsApp**، واربط رقمًا (أو استخدم رقم الاختبار المؤقت).
3. من لوحة WhatsApp احصل على:
   - **Access Token** ← ضعه في `WHATSAPP_TOKEN` (يُفضّل توليد رمز دائم Permanent Token).
   - **Phone Number ID** ← ضعه في `WHATSAPP_PHONE_NUMBER_ID`.
4. اختر رمز تحقق سريًا وضعه في `WHATSAPP_VERIFY_TOKEN` (نفسه ستضعه في خطوة Webhook).

### 4) مفتاح Claude
ضع مفتاح Anthropic في `ANTHROPIC_API_KEY`. النموذج الافتراضي `claude-opus-5`
(الأذكى للإقناع). لتكلفة أقل مع جودة عالية جدًا استخدم `MODEL=claude-sonnet-5`.

### 5) شغّل الخادم واعرضه للإنترنت
```bash
npm start
```
الخادم يعمل على `PORT` (افتراضيًا 3000). لتجربته محليًا اعرضه عبر نفق مثل
[ngrok](https://ngrok.com/): `ngrok http 3000` — ستحصل على رابط `https://...`.
للإنتاج انشره على أي خادم يدعم HTTPS (Railway / Render / VPS...).

### 6) اربط الـ Webhook داخل Meta
في إعدادات WhatsApp > Configuration > Webhook:
- **Callback URL**: `https://نطاقك/webhook`
- **Verify token**: نفس `WHATSAPP_VERIFY_TOKEN`.
- بعد التحقق، اشترك في حقل **messages**.

الآن أي رسالة تصل رقمك ستُقرأ، ويظهر مؤشّر الكتابة، وبعد ~10 ثوانٍ يصل ردّ بيعي ذكي. ✅

## متغيرات البيئة
| المتغير | الوصف |
|---|---|
| `WHATSAPP_TOKEN` | رمز الوصول من Meta |
| `WHATSAPP_PHONE_NUMBER_ID` | معرّف رقم الهاتف |
| `WHATSAPP_VERIFY_TOKEN` | رمز التحقق (تختاره أنت) |
| `ANTHROPIC_API_KEY` | مفتاح Claude |
| `MODEL` | النموذج (افتراضي `claude-opus-5`) |
| `REPLY_DELAY_MS` | الانتظار قبل الرد بالمللي ثانية (افتراضي 10000) |
| `HUMAN_HANDOFF_NOTE` | رسالة التحويل لمختص بشري |

## ملاحظات
- الذاكرة حاليًا **في الذاكرة (in-memory)** وتُفقد عند إعادة التشغيل. للإنتاج طويل الأمد
  استبدل `store.js` بقاعدة بيانات (Redis / SQLite / Postgres) بنفس الواجهة.
- بعد ساعات من صمت العميل، يشترط واتساب استخدام قالب رسائل معتمد (خارج نافذة الـ 24 ساعة).
  هذا النظام يخدم الردود ضمن نافذة الـ 24 ساعة (رد على محادثة نشطة).
